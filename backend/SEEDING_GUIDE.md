After fixing `DatabasesSqlAdvancedSeeder.php`,
paste this into your host terminal from the repository root. It uses Python 3
and Docker, checks the syntax of every selected file before
starting the quiz import, and runs one PHP process per file to avoid duplicate
class names. It excludes cleanup seeders and the alternate computer-science
curriculum seeder.

```bash
python3 - <<'PY'
from pathlib import Path
import re
import subprocess
import sys

root = Path('backend/database/seeders')
levels = {'Beginner': 0, 'Intermediate': 1, 'Advanced': 2, 'Professional': 3}
pattern = re.compile(r'(Beginner|Intermediate|Advanced|Professional)Seeder\.php$')
files = [p for p in root.rglob('*.php')
         if 'verified and finished ready to seed' in p.parent.name
         and pattern.search(p.name)]
files.sort(key=lambda p: (str(p.parent), pattern.sub('', p.name),
                          levels[pattern.search(p.name).group(1)]))
if not files:
    sys.exit('No quiz seeders found. Run this from the repository root.')

entries = []
errors = []
for path in files:
    relative = str(path.relative_to('backend'))
    result = subprocess.run(
        ['docker', 'exec', 'quizatlas-php', 'php', '-l', relative],
        stdout=subprocess.PIPE, stderr=subprocess.STDOUT, text=True)
    if result.returncode:
        errors.append(result.stdout)
        continue
    source = path.read_text(encoding='utf-8-sig')
    namespace = re.search(r'^\s*namespace\s+([^;]+);', source, re.M)
    name = re.search(r'^\s*class\s+(\w+)\s+extends\s+Seeder', source, re.M)
    if not namespace or not name:
        errors.append(f'Cannot identify seeder class: {relative}')
        continue
    entries.append((relative, namespace.group(1).strip() + '\\' + name.group(1)))

if errors:
    print('\n'.join(errors))
    sys.exit('Stopped before importing quiz files. Fix these errors and retry.')

runner = r'''
require 'vendor/autoload.php';
$app = require 'bootstrap/app.php';
$kernel = $app->make(\Illuminate\Contracts\Console\Kernel::class);
$kernel->bootstrap();
require_once $argv[1];
$status = $kernel->call('db:seed', ['--class' => $argv[2]]);
echo $kernel->output();
exit($status);
'''

for index, (relative, classname) in enumerate(entries, 1):
    print(f'[{index}/{len(entries)}] {relative}', flush=True)
    subprocess.run(['docker', 'exec', 'quizatlas-php', 'php', '-r',
                    runner, relative, classname], check=True)

print(f'Completed {len(entries)} quiz seeder files.')
PY
```

If a runtime error occurs, the script stops at that file. Inspect and correct the
error before continuing. It does not run destructive cleanup seeders automatically.

For a smaller first import, change the `files` selection to the desired folder

**6. Generate community activity and earned achievements**

Only after your quiz content is ready, run:

```bash
docker exec quizatlas-php php artisan db:seed --class=DemoCommunitySeeder
```

The wrapper runs these steps:

| Seeder | Result |
| --- | --- |
| `UserSeeder` | Creates missing fixture users and updates their readable usernames |
| `LeaderboardSeeder` | Ensures achievement definitions exist, then records varied quiz answers and results using existing scoring and gamification services |
| `UserAchievementSeeder` | Backfills missing eligible badges for those fixture users |

XP, levels, accuracy, completion counts and streaks now have recorded activity
behind them. Inactive and new profiles differ from experienced profiles. Students
with existing attempts, XP transactions, or badges keep their recorded activity.
The bounded quiz pool samples up to four subjects per available major; it does
not guarantee demo rankings in every subject.

If no playable public quizzes exist, users and the 10 achievement definitions
are created, and activity generation is skipped with a message. Import quiz
content and run this command again.

Run the community wrapper again when you only need to refresh fixture usernames
or fill missing community data. Reimporting quiz content after users have recorded
answers needs separate care because those content seeders can replace choice IDs.
